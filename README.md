# AFTERHOURS — Couples Prototype

Local, buildless interactive prototype for a private adult couples game night. It includes a mood selector, individual theme configuration, a consent-first flow, randomized alternate rounds, optional timers, and pause/exit controls.

Open `index.html` in a browser, or serve this folder with any static web server.

This prototype deliberately contains no accounts, payments, analytics, remote storage, messaging, or sensitive-data collection.
